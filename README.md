One line from a tech support agent who has officially given up — politely: **"I hear you — let's turn it off and on again, and if that fails I'll escalate you to a team who will also ask you to turn it off and on again."** Empathy first, the classic fix second, escalation to nowhere third. The joke is the agent's cheerful surrender, never the customer's desperation.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (no trailing newline) and prints it to stdout. Deterministic, standard library only, no network.
